# 段取り帳

一日のスケジュールを組み立てるためのツールです。時刻の決まった予定（授業・食事など）を先に置き、残りのやることを所要時間と優先度から空き時間へ自動で並べます。

## 使い方

- 公開ページを開くとそのまま使えます。
- 予定のデータは、開いたブラウザの中（localStorage）だけに保存されます。GitHub には送られません。
- 別の端末に移すときは「組み方の設定とバックアップ」→「全データをコピー」で控えを取り、移した先で貼り付けて戻します。

## ブラウザから編集する

1. このリポジトリで `index.html` を開き、右上の鉛筆アイコン（Edit this file）を押します。
2. 書き換えたら「Commit changes」を押します。
3. 1〜2分ほどで公開ページに反映されます。

まとめて手を入れたいときは、リポジトリのページでキーボードの `.` を押すと、ブラウザ上のエディタ（github.dev）が開きます。

## ファイル

- `index.html` — ページ本体（HTML・CSS・JavaScript がこの1ファイルに入っています）
