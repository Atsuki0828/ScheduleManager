# 段取り帳

一日のスケジュールを組み立てるためのツールです。時刻の決まった予定（授業・食事・Googleカレンダーの予定など）を先に置き、残りのやることを所要時間と優先度から空き時間へ自動で並べます。

公開ページ: https://atsuki0828.github.io/ScheduleManager/

## できること

- やることを所要時間・優先度・分類つきで追加すると、空き時間に自動で配置（作業が続くと休憩を挟む）
- 時間軸のブロックをドラッグで移動、下端で長さを調整（スマホは長押ししてから動かす）
- クリックで選択、Shift+クリックで複数選択、ダブルクリックで編集（スマホはタップで選択、続けてタップで追加）
- 選択中の予定を、右クリックメニューか画面下の操作バーからまとめて編集・複製（その日／次の日／その週）・完了・削除
- Googleでログインし、Googleカレンダーの予定を時間軸に表示。その予定を避けて段取りを組む
- 週の見通し（7日分の予定量）
- 毎日のルーティン（曜日指定。今日以降の日を開くと自動で入る）
- あとでやるリスト（日付を決めずに置いておき、好きな日に入れる）
- 元に戻す（Ctrl / ⌘ + Z）
- 「いま」の予定を完了にする、15分のばして後ろを組み直す
- 予定が始まる5分前の通知（ページを開いている間）
- 前日の残りの持ち越し、先週の同じ曜日の予定の写し、テキストでコピー

予定のデータは、開いたブラウザの中（localStorage）だけに保存されます。GitHub には送られません。別の端末に移すときは「組み方の設定とバックアップ」→「全データをコピー」で控えを取り、移した先で貼り付けて戻します。

## Googleカレンダー連携の準備（最初の1回だけ）

Googleでログインするには、Google Cloud で「OAuth クライアントID」を作り、`index.html` の `GOOGLE_CLIENT_ID` に入れます（ページの設定欄に貼っても動きます）。

1. https://console.cloud.google.com/ で新しいプロジェクトを作る（名前は例: dandori）
2. 「APIとサービス」→「ライブラリ」で **Google Calendar API** と **Google Drive API** を有効にする（Drive は端末間の同期に使います）
3. 「APIとサービス」→「OAuth 同意画面」（Google Auth Platform）で
   - アプリ名: 段取り帳、ユーザーの種類: 外部
   - 「対象」のテストユーザーに自分の Gmail アドレスを追加
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - アプリケーションの種類: ウェブ アプリケーション
   - 承認済みの JavaScript 生成元: `https://atsuki0828.github.io`
5. 表示されたクライアントID（`〜.apps.googleusercontent.com`）を、`index.html` 冒頭の `GOOGLE_CLIENT_ID=''` の引用符の中に入れてコミット

使う権限は、カレンダーの「閲覧のみ」と、Googleドライブの「このアプリ専用の保存領域」だけです。ドライブのほかのファイルは読みも書きもしません。

## Googleカレンダー「段取りスケジュール」への書き出し

Googleの欄の「「段取りスケジュール」に書き出す」を押すと、Googleカレンダーに **段取りスケジュール** という専用カレンダーが作られ、段取り帳で組んだ予定（時刻を決めた予定と自動で配置した予定。休憩と例は除く）がそこに反映されます。

- 書き込むのはこの専用カレンダーだけです。使う権限（calendar.app.created）は「このアプリが作ったカレンダーだけを操作できる」ものなので、ほかのカレンダーの予定を変えたり消したりすることはできません。
- 段取り帳で予定を足す・動かす・消すと、数秒後に専用カレンダーにも同じ変更が入ります。完了にした予定は頭に ✓ が付きます。
- 専用カレンダーの予定はGoogleカレンダー側で直さず、段取り帳で直してください（次の書き出しで段取り帳の内容に戻ります）。
- 専用カレンダーは取り込み元から外してあるので、段取り帳の時間軸に二重に出ることはありません。
- 「止める」を押すと書き出しをやめます。専用カレンダーに入っている予定は残るので、要らなければGoogleカレンダーの設定でカレンダーごと削除してください。

## 端末間の同期

同じGoogleアカウントでログインした端末どうしで、予定・あとでやる・ルーティン・設定が同期されます。データは自分のGoogleドライブの、このアプリだけが使う隠しフォルダ（appDataFolder）に `dandori.json` として保存されます（ドライブの一覧には表示されません）。

- 変更すると数秒後に送られ、ほかの端末では開いたときと1分ごとに取り込まれます。
- 同じ日を2台で別々に変えたときは、あとから変えた方の内容がその日の分として残ります。
- ログインは安全のため1時間ごとに切れます。切れたあとに予定を編集すると自動でつなぎ直します（一瞬ポップアップが出ます）。「再接続」を押しても構いません。

## ブラウザから編集する

1. このリポジトリで `index.html` を開き、右上の鉛筆アイコン（Edit this file）を押します。
2. 書き換えたら「Commit changes」を押します。
3. 1〜2分ほどで公開ページに反映されます。

まとめて手を入れたいときは、リポジトリのページでキーボードの `.` を押すと、ブラウザ上のエディタ（github.dev）が開きます。
