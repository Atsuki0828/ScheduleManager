# 段取り帳

一日のスケジュールを組み立てるためのツールです。時刻の決まった予定（授業・食事・Googleカレンダーの予定など）を先に置き、残りのやることを所要時間と優先度から空き時間へ自動で並べます。

公開ページ: https://atsuki0828.github.io/ScheduleManager/

## できること

- やることを所要時間・優先度・分類つきで追加すると、空き時間に自動で配置（作業が続くと休憩を挟む）
- 時間軸のブロックをドラッグで移動、下端で長さを調整（スマホは長押し）
- 右クリック（スマホは長押しで止める）で「編集」「複製」
- Googleでログインし、Googleカレンダーの予定を時間軸に表示。その予定を避けて段取りを組む
- 週の見通し（7日分の予定量）
- 毎日のルーティン（曜日指定。今日以降の日を開くと自動で入る）
- あとでやるリスト（日付を決めずに置いておき、好きな日に入れる）
- 元に戻す（Ctrl / ⌘ + Z）
- 「いま」の予定を完了にする、15分のばして後ろを組み直す
- 予定が始まる5分前の通知（ページを開いている間）
- 前日の残りの持ち越し、先週の同じ曜日の予定の写し、テキストでコピー

予定のデータは、開いたブラウザの中（localStorage）だけに保存されます。GitHub には送られません。別の端末に移すときは「組み方の設定とバックアップ」→「全データをコピー」で控えを取り、移した先で貼り付けて戻します。

## Googleカレンダー連携の準備（最初の1回だけ）

Googleでログインするには、Google Cloud で「OAuth クライアントID」を作り、`index.html` の `GOOGLE_CLIENT_ID` に入れます（ページの設定欄に貼っても動きます）。

1. https://console.cloud.google.com/ で新しいプロジェクトを作る（名前は例: dandori）
2. 「APIとサービス」→「ライブラリ」で **Google Calendar API** を有効にする
3. 「APIとサービス」→「OAuth 同意画面」（Google Auth Platform）で
   - アプリ名: 段取り帳、ユーザーの種類: 外部
   - 「対象」のテストユーザーに自分の Gmail アドレスを追加
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - アプリケーションの種類: ウェブ アプリケーション
   - 承認済みの JavaScript 生成元: `https://atsuki0828.github.io`
5. 表示されたクライアントID（`〜.apps.googleusercontent.com`）を、`index.html` 冒頭の `GOOGLE_CLIENT_ID=''` の引用符の中に入れてコミット

使う権限はカレンダーの「閲覧のみ」です。ログインは安全のため1時間ごとに切れるので、そのときは「再接続」を押します。

## ブラウザから編集する

1. このリポジトリで `index.html` を開き、右上の鉛筆アイコン（Edit this file）を押します。
2. 書き換えたら「Commit changes」を押します。
3. 1〜2分ほどで公開ページに反映されます。

まとめて手を入れたいときは、リポジトリのページでキーボードの `.` を押すと、ブラウザ上のエディタ（github.dev）が開きます。
